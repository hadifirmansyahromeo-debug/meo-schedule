# Meo Schedule

Aplikasi web sederhana untuk membuat dan mengatur jadwal pelajaran.

## Fitur
- Tambah nama pelajaran, hari, jam mulai, jam selesai, dan ruangan opsional.
- Filter jadwal berdasarkan hari.
- Hapus jadwal.
- Jadwal tersimpan otomatis di browser/perangkat menggunakan `localStorage`.
- Tampilan responsif untuk HP dan komputer.

## Menjalankan di komputer
1. Ekstrak file ZIP.
2. Buka `index.html` di browser.

## Upload ke GitHub dan aktifkan GitHub Pages
1. Buat repository baru di GitHub, misalnya `meo-schedule`.
2. Upload `index.html` dan `README.md` ke repository.
3. Buka **Settings → Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu tekan **Save**.
6. Tunggu proses selesai; GitHub akan memberikan alamat website.

## Catatan
Ini adalah versi aplikasi web, bukan APK Android yang sudah dikompilasi. Bisa dibuka lewat browser HP dan dipublikasikan dengan GitHub Pages. Data jadwal disimpan lokal di browser yang digunakan, jadi tidak otomatis tersinkron ke perangkat lain.
